## Continue from your phone

1. Open the **Claude** app (or claude.ai/code in the phone browser) and start a **Claude Code** session on this repo (`kumar98rishav-oss/Claude-AI-Power-BI`). Connect GitHub the first time it asks.
2. Claude reads `CLAUDE.md` automatically, so it knows the programme, the dataset and what's next.
3. Ask for what you need, e.g. "Draft the Session 2 slide outline in docs/" or "Turn the Session 2 plan into a transcript". Claude commits the changes back here.
4. Reading only? GitHub's app shows every `.md` file nicely, and the PDFs open in the browser.

Things that need the laptop: running Power BI Desktop, connecting the MCP server, recording Performance Analyzer, and rebuilding the PPTX.

## Rebuild the deck (laptop)

The deck is generated by `session-01/build/build_session01.js` with [pptxgenjs](https://www.npmjs.com/package/pptxgenjs). It reuses the theme and helpers in `build_deck.js` and the images in `assets/`. Install `pptxgenjs` in a folder, point `NODE_PATH` at its `node_modules`, then run `node build_session01.js`. Set `OUT=<path>` to write somewhere else (useful when the deck is open in PowerPoint).

## Before you run Session 01

- **Re-record Performance Analyzer.** `PowerBIPerformanceData.json` is not in this repo (it was removed locally). Open `pbip-project/MeridianSupplyChain.pbip`, then Optimize › Performance analyzer › Start recording › Refresh visuals › click the other two pages › Stop › Export, and save it next to the `.pbip`.
- Register the server: `claude mcp add --scope user powerbi-modeling '--' cmd /c npx -y @microsoft/powerbi-modeling-mcp@latest --start --readonly`

## Data note

Meridian Medical Supply is a fictional company; all data in this repo is generated. Never put a client's model or data here, and never commit API keys.
